# Eigenbeing — N-Body Simulator

An interactive Eigenbeing animation by Hewmorist, synchronized with [Eigenbeing (Animation) on SoundCloud](https://soundcloud.com/hewmorist/eigenbeing-electronic-cut).

Press Play to begin. Pause stops music and animation; Restart starts both from the beginning. Drag or swipe to explore, and use the wheel or pinch to zoom while playing or paused. Fit Screen frames the current bodies; Recorded View returns to the animation camera.

Release: n-body-deploy-13. Responsive phone and laptop layouts, including a compact control row on wide screens. The animation runs for350 simulation seconds. Audio streams through the official hidden SoundCloud widget; visuals continue after the track ends. A browser with WebGL2 is required.

Static release files are served from the repository root. For GitHub Pages, choose Settings → Pages → Deploy from a branch → eigenbeing-deploy → /(root). No build step is required.
