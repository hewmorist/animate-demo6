# Eigenbeing — N-Body Simulator

An interactive animation by Hewmorist, synchronized with [Eigenbeing (Animation) on SoundCloud](https://soundcloud.com/hewmorist/eigenbeing-electronic-cut).

Press Play to begin. Pause stops music and animation; Restart starts both from the beginning. Drag or swipe to explore, and use the wheel or pinch to zoom while playing or paused. Fit Screen frames the current bodies; Recorded View returns to the animation camera.

Release: n-body-deploy-14, Eigenbeing Rev2. The animation runs for315 simulation seconds (5:15), ending about3seconds after the track when the device keeps pace. Responsive phone and laptop layouts, including a compact control row on wide screens. Audio streams through the official hidden SoundCloud widget. A browser with WebGL2 is required.

Static release files are served from the repository root. GitHub Pages source: eigenbeing-deploy, /(root). No build step is required.
