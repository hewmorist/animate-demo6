# Eigenbeing — N-Body Simulator

An interactive Eigenbeing animation by Hewmorist, synchronized with its SoundCloud track.

Press Play to begin. Pause stops music and animation; Restart starts both from the beginning. Drag or swipe to explore, and use the wheel or pinch to zoom while playing or paused. Fit Screen frames the current bodies; Recorded View returns to the animation camera.

Release: n-body-deploy-10. The animation runs for 350 simulation seconds. SoundCloud audio streams through its official hidden widget; the visuals continue after the track ends. A browser with WebGL 2 is required.

This branch contains the static release files, ready to serve from the repository root. For GitHub Pages, select Settings → Pages → Deploy from a branch → eigenbeing-deploy → /(root). No build step is required.
